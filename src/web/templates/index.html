How to Authenticate with API Keys

Pass the raw API key either via the X-API-Key request header or standard Authorization: Bearer rp_live_....

cURL Example 
curl -H "X-API-Key: rp_live_xxxxxxxx..." \
     http://127.0.0.1:8000/api/ranges
Python requests Example 
import requests
res = requests.get(
    "http://127.0.0.1:8000/api/ranges",
    headers={"X-API-Key": "rp_live_xxxxxxxx..."}
)
